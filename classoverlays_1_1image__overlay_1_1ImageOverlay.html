Detailed Description

Memory-safe presentation container handling dynamic campaign image rotation.

Automatically shifts asset pipelines between landscape (_h) and portrait (_v) orientations based on bounding box changes. Implements a debounced timer mechanism to prevent disk-read thrashing during active layout transformations.
